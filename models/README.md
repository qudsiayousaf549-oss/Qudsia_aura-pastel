# Models placeholders

This folder contains tiny placeholder files as markers. Replace the placeholders with your high-resolution GLB/GLTF assets named exactly as below or update the HTML files to point to your asset URLs.

Recommended filenames and paths:
- models/sofa.glb
- models/closet_preview.glb

Notes:
- For production, host optimized, draco-compressed GLB files on a CDN and reference them from the pages.
- Ensure PBR materials are included in the GLB for photoreal rendering (baseColor, metalness, roughness, normal maps).
