# Sound placeholders

Audio assets are synthesized in-browser by default (no external files required). To use bespoke cinematic sound effects, replace these placeholders with your mastered audio files and update the pages to load them.

Suggested filenames (if you want to add files here):
- assets/sounds/closet-open.mp3
- assets/sounds/closet-close.mp3
- assets/sounds/ui-click.mp3
- assets/sounds/zoom.mp3

If you add audio files, ensure licensing is appropriate for distribution.
